# 🎧 Dictation-Tool

A mini web app for anyone who wants to train dictation.

Just copy-paste your text and fight! 🔥

## ✨ Features

- 🔊 Text-to-Speech
- 🎙️ Speech Recognition
- 📝 Dictation practice
- ✅ Word-by-word answer checking
- 📖 Transcript view
- ⏩ Adjustable playback speed
- 🌎 Multiple languages
- 💾 Progress saved with localStorage
- 📱 Responsive UI

## 🚀 How to use

1. Create a text.
2. Paste your text.
3. Choose your language and speed.
4. Start listening.
5. Write what you hear.
6. Check your answer.
7. Use Transcript to listen and practice speaking.

## 🛠️ Built with

- HTML
- CSS
- JavaScript
- Web Speech API
- localStorage
